## 目标与范围

将交互 Path 替换为完整的 RTRT 管线，保留 OpenGL 模式及离线高采样路径追踪。新会话默认进入 RTRT；CUDA 不可用时回退 OpenGL 并显示原因。

采用已确认的 **CUDA 首交点、低采样光追、自研时空降噪、TAA／时域上采样** 路线。首版优先功能、画质和动态稳定性，记录实际性能，不设置固定帧率门槛。保留现有课程笔记的未提交改动。

## 渲染管线

每帧执行完整流程：

```text
场景增量同步
→ 抖动相机与首交点 G-buffer
→ 低采样直接光、阴影、GI、反射与折射
→ 异常亮点抑制
→ 重投影与时域统计
→ 方差估计与 à-trous 保边滤波
→ 光照合成
→ TAA／时域上采样
→ 现有曝光、色调映射与显示
```

- **复用底层能力。** 抽取现有 CUDA 场景上传、BLAS/TLAS、材质、GGX／Kulla–Conty、纹理和采样代码，由 RTRT 与离线参考共用。替换交互端的低清预览、静止等待和跨帧分块累积策略；每次渲染都发布完整的新画面。
- **完整光照。** 支持直接光、真实遮挡、软阴影、多次反弹 GI、粗糙反射、镜面和玻璃折射。接通光源半径、太阳角半径和 `casts_shadows`；保留面积光、发光几何及环境光的重要性采样与 NEE/MIS，避免重复计入环境光能量。
- **分离光照信号。** 区分直接／间接贡献，并分别重建漫反射、镜面和透射。拆分 BRDF 时保留正确的 PDF 与能量权重；漫反射进行材质解调、滤波后复调，直接可见的发光和背景单独合成。
- **建立可靠 G-buffer。** 保存线性深度、几何／着色法线、材质属性、稳定对象与表面标识、运动向量及镜面命中距离。按对象 ID 保存上一帧变换，支持相机运动、刚体移动及实例重排。运动向量统一为“当前指向历史”的 UV 位移，jitter 单独补偿。
- **实现 SVGF 风格重建。** 顺序采用历史重投影、颜色与一二阶矩累积、短历史空间方差估计、逐轮扩大步长的 à-trous。历史插值逐样本验证深度、法线和身份；滤波使用独立读写缓冲，第一轮空间结果作为颜色反馈。阶段组织参考 [SVGF 原始研究](https://research.nvidia.com/publication/2017-07_spatiotemporal-variance-guided-filtering-real-time-reconstruction-path-traced)。
- **处理历史失效。** 普通相机和刚体运动保留可用历史；镜头切换、尺寸变化、场景替换和不兼容几何变化重置历史。灯光、材质和遮挡变化通过反应掩码、历史钳制及提高当前帧权重快速响应。颜色、矩、历史长度同步失效，场景上传标记不直接等同于全局重置。
- **分别处理反射与透明。** 镜面采用粗糙度、命中距离和较短历史；理想镜面与透射跳过宽核空间模糊。保留现有 Alpha Mask／Blend 和玻璃语义，对不可靠的透明历史降低复用。
- **实现 TAA／TAAU。** 使用独立的最终图像历史，处理子像素覆盖、重投影和历史裁剪。低分辨率输入重建至输出尺寸；深度、法线和 ID 按表面选择，不能直接平均。曝光和调试视图不污染光照历史。

GPU 缓冲与工作队列持续复用；正常 CUDA–OpenGL 互操作路径不下载整帧到 CPU。

## 接口、参数与 ImGui

新增独立的 `RealtimeRenderSettings`、RTRT 后端和阶段统计类型；帧状态增加明确的镜头切换信息。输出尺寸与 RTRT 内部采样比例分别管理。

交互模式改为 `OpenGL / RTRT`，快捷键为 `1 / 2`。新增 `--mode rtrt`，交互端旧 `--mode path` 作为别名；离线 `renderer` 继续提供高采样 Path。

`Techniques` 窗口保持固定停靠位置，随模式切换内容；两种模式的参数分别保存。

| 面板 | 主要开关和参数 |
|---|---|
| 公共面板 | 场景、相机、灯光与环境编辑、输出尺寸、曝光、色调映射 |
| OpenGL 技术 | NPR、IBL、LTC、阴影／PCSS、AO、SSR、SSGI 及各自调试参数 |
| RTRT 光照与采样 | 每帧 SPP、路径深度、Russian roulette、直接光、阴影、GI、反射、折射、光源采样预算 |
| RTRT 降噪 | 总开关、时域复用、分信号历史长度、深度／法线阈值、历史钳制、亮点抑制、方差权重、à-trous 轮数 |
| RTRT 图像重建 | TAA、内部采样比例、TAAU、历史权重、裁剪和锐化强度 |
| RTRT 调试与性能 | 原始光照、各光照分量、G-buffer、运动向量、方差、历史长度、拒绝／反应掩码、滤波结果、各阶段 GPU 耗时和显存占用 |

默认采用 **1 SPP、最多 8 层路径、100% 内部分辨率**，开启全部光照分量、SVGF 和 TAA。漫反射／镜面／透射历史上限分别为 **32／8／4 帧**；漫反射／粗糙镜面空间滤波默认 **5／3 轮**。降低内部分辨率时启用 TAAU。

会话版本由 5 升至 6，保存两套技术参数并兼容旧会话。旧 Path 模式映射到 RTRT，旧暂停和自动预览状态不带入新管线。删除对应的过时面板、统计和提示。

## 验证与交付

- **数学与 GPU 测试：** 常量保持、几何断层保边、斜平面深度容差、运动向量方向、jitter 补偿、历史拒绝、矩重置、滤波轮次依赖及 NaN／Inf。
- **光照与材质测试：** 各类灯光及阴影开关、离屏反射、漫反射反弹、粗糙金属、玻璃、透明贴图、发光体和环境光；关闭重建后，与同灯光模型、同路径深度的高 SPP 参考对照。
- **动态画质验证：** 固定相机移动光源、移动镜中物体、前景移开、快速转镜、切镜及连续拖动实例。输出原始、降噪、最终图像和诊断序列，检查拖影、漏光、串色和过度模糊。
- **量化对照：** 用固定种子的 Cornell、反射／玻璃和纹理边缘场景，对比高 SPP 参考；记录重建前后误差、静态闪烁及变化后的响应。比较原生 TAA 与低分辨率 TAAU。
- **应用与兼容性：** 验证模式切换同步更换面板、参数往返保存、旧会话迁移、缩放、CUDA 不可用回退和互操作失败回退。
- **实际运行：** 完成 CUDA 与无 CUDA 构建、CTest 及 CUDA 内存检查；在当前 RTX 3050 Laptop 上执行至少 300 帧 RTRT smoke，确认 `interop=active`、正常运行零整帧下载，并报告完整出图率和阶段耗时。

实施顺序为：**共享底层与参考 → RTRT 采样及 G-buffer → 时空降噪 → TAAU → 面板与迁移 → 动态验证**。最终交付可运行构建、对照图像及使用说明。首版不引入新图形后端、神经降噪 SDK、ReSTIR 或 Probe GI。
