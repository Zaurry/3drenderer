# v0.1 输出结果说明

## 版本信息

- 分支: `feature/cpu-renderer-v0.1`
- 目标: 从零实现一个教学型 CPU 3D 渲染器，覆盖光栅化、Whitted 光线追踪、路径追踪和 OBJ 加载。
- 约束: 不使用 OpenGL、Vulkan、DirectX、Embree、OptiX 或 CUDA。

## 构建环境

- OS: Microsoft Windows 11 专业版 10.0.26200
- CPU: AMD Ryzen 7 5800H with Radeon Graphics, 8 cores / 16 logical processors
- CMake: 4.3.2
- Generator: Visual Studio 17 2022
- Compiler: MSVC 19.42.34435.0
- Build type: Release

## 本版实现内容

- Core: `Vec2/Vec3/Vec4/Mat4`、射线、AABB、颜色转换、PNG 输出、计时器、确定性 RNG。
- Scene: 材质、点光、方向光、球、三角形、相机、内置示例场景。
- Acceleration: 三角形 BVH，按最长轴切分，叶子节点最多 4 个三角形。
- Rasterizer: 手写 CPU 三角形光栅化、屏幕投影、重心坐标、深度缓冲、Lambert + Blinn-Phong 光照。
- Ray tracer: Whitted 光追，支持阴影光线、反射、折射、递归深度限制和 BVH 三角形遍历。
- Path tracer: tile 多线程路径追踪，支持像素内随机采样、漫反射半球采样、金属粗糙反射、玻璃反射/折射、自发光材质。
- OBJ: 使用 `tinyobjloader` 单头文件解析 OBJ，再转换为项目自己的 `Triangle`。
- CLI: `--mode raster|ray|path` 与 `--scene ...` 统一入口，未来可以继续扩展到统一渲染接口。

## 示例图片

渲染输出位于 `output/`:

- `output/raster_triangle.png`: 软件光栅化三角形。
- `output/mirror_spheres.png`: Whitted 光追镜面球场景。
- `output/cornell_box.png`: 路径追踪 Cornell box 风格场景。

## 复现命令

```powershell
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
.\build\bin\renderer_tests.exe

.\build\bin\renderer.exe --mode raster --scene raster_triangle --width 512 --height 512 --output output\raster_triangle.png
.\build\bin\renderer.exe --mode ray --scene mirror_spheres --width 512 --height 512 --output output\mirror_spheres.png
.\build\bin\renderer.exe --mode path --scene cornell_box --width 512 --height 512 --spp 32 --max-depth 5 --output output\cornell_box.png
```

## 已知限制

- 光栅化器暂未实现完整裁剪，示例几何需要位于相机近裁剪面前方。
- 路径追踪器没有直接光采样、MIS、Russian roulette、降噪和物理完整 PBR BSDF。
- BVH 只加速三角形，球体仍直接遍历。
- OBJ 查看器暂不解析材质和贴图。
- 当前只输出离线 PNG，没有实时交互窗口或 GPU 后端。

## 下一步路线图

- 抽象统一渲染接口和 pass/scene resource 生命周期。
- 给路径追踪加入 next event estimation、MIS、Russian roulette 和更完整的材质模型。
- 给光栅化加入完整裁剪、透视正确属性插值、纹理采样和更丰富的 framebuffer。
- 扩展 OBJ/材质/贴图加载，并加入更复杂的示例模型。
- 增加性能统计、tile 进度、基准测试和更多图像回归测试。
